
### What was new to me
- Copilot kann Bilder analysieren und das Design einer Webseite anhand eines Referenzbildes mit HTML und CSS nachbauen.
- Copilot kann den integrierten Browser selbstständig öffnen und Eingabefelder mit Testdaten ausfüllen.
- Mir war neu, dass Copilot die Webseite direkt im Browser testen und überprüfen kann, ob die Funktionen richtig arbeiten.
- Ich habe gelernt, dass ich in der `AGENTS.md` allgemeine Anweisungen festlegen kann, die Copilot bei der Implementierung berücksichtigen soll.
- Copilot kann mehrere zusammenhängende Dateien wie `index.html`, `style.css` und `script.js` bearbeiten.

### New things I did learn
- Ich habe gelernt, wie ich eine Webseite mithilfe einer `SPEC.md` in einzelne Features aufteilen kann.
- Durch die schrittweise Implementierung kann ich Fehler leichter erkennen und nachvollziehen, welcher Code zu welcher Funktion gehört.
- HTML ist für den Aufbau der Webseite zuständig, CSS für das Design und JavaScript für die Funktionen.
- Mit JavaScript kann ich Werte aus Formularfeldern auslesen und weiterverarbeiten.
- Mit `localStorage` können eingegebene Daten direkt im Browser gespeichert werden, sodass sie nach dem Neuladen erhalten bleiben.
- Ich habe gelernt, dass ich Copilot konkrete Anweisungen geben kann, damit bestehende Funktionen nicht unbeabsichtigt verändert werden.
- Durch das Testen im integrierten Browser kann ich überprüfen, ob die Eingabefelder, Buttons und gespeicherten Daten richtig funktionieren.
- Je genauer ich meine Anforderungen beschreibe, desto besser kann Copilot das gewünschte Ergebnis umsetzen.

### Tips and tricks
- Ich habe Copilot gebeten, immer nur ein Feature aus der `SPEC.md` zu implementieren.
- Ich habe das Referenzbild als Designvorlage festgelegt, damit die Webseite einheitlich gestaltet wird.
- Ich habe Copilot angewiesen, einfachen und verständlichen Code zu schreiben.
- Ich kann Copilot bitten, Fehler direkt im integrierten Browser zu überprüfen und anschließend zu korrigieren.
- Wenn mir ein Ergebnis nicht gefällt, kann ich Copilot gezielt sagen, welcher Bereich angepasst werden soll, anstatt die gesamte Webseite neu erstellen zu lassen.
